# AgentHub MCP Server Runtime (Go)

**MCP Server** - Expor capacidades do AgentHub via MCP.

## Responsabilidades
- Expor skills/agents via MCP
- Implementar protocolo MCP server
- Autenticação e rate limiting
- Integração com Backend (HTTP)

## Capabilities Expostas
- Tools (skills do AgentHub)
- Agent execution
- Knowledge base search
- Package installation

## Tech Stack
- Go 1.21+
- MCP SDK
- HTTP client para Backend
